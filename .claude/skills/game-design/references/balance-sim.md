# 平衡模擬（Monte Carlo）手冊

## 1. 架構原則
- **模擬機制，不驅動客戶端**：Google 的研究中，直接驅動遊戲客戶端只能人速執行；獨立模擬器快約 1,000 倍。本作：`sim/` 內實作同規則的 headless 落沙 + 計分 + 商店。
- **單一資料來源**：材料、反應表、催化劑、價格全放 `data/*.json`（或 CSV），Unity 與 sim 都讀它。任何數值只改資料檔。
- **一致性測試**：同 seed 同輸入，Unity 版與 sim 版的反應計數與分數必須相同（或在可解釋的容差內）。每次改模擬核心都要跑。
- 粗模擬也可以：若完整落沙太慢，sim 用「縮小網格（如 80×60）」或「反應統計代理模型」，但要定期用完整模擬校準代理模型。

## 2. Bot 等級
| Bot | 倒料策略 | 商店策略 | 用途 |
|---|---|---|---|
| Random | 隨機 vial、隨機位置 | 隨機買得起的 | 下限；勝率應 < 5% |
| Greedy | 每個 vial × 8–16 個候選位置模擬，選最高分 | 依物件「啟發式估值」買 | 代表稱職玩家；白注勝率 30–50% |
| Archetype | Greedy + 鎖定某原型，優先買該原型物件 | 同左 | 測每個原型是否可行 |
| Lookahead | beam search / MCTS 看 1–2 步 | 估值 + 預算規劃 | 代表高手；白注 80–95% |

- 注意：bot 只會最佳化你給它的評估函數（Google 研究的警告）。延遲收益（Scaling 類物件）若沒進估值，bot 會低估它。估值 = 「買下後模擬接下來 3 回合的期望分數增量」最客觀但最慢。
- 倒料候選位置要包含「玩家會想到的」位置（邊角、液面上、火源旁），不要只均勻取樣。

## 3. 每輪模擬至少輸出
- 整體：每 bot 勝率（含 95% 信賴區間；N=1,000 時 ±3pp）、死亡 ante 分佈、平均局長（以回合數與估計秒數）。
- 物件：出現率、拿取率（被提供時被買的比例）、**勝率差 = 持有時勝率 − 基準勝率**、平均分數貢獻（移除該物件重算當倒分數的差，ablation）。
- 原型：佔勝場比例、Shannon entropy（越高越多元；5 個原型均分時 = log2(5) ≈ 2.32）。
- 經濟：每店平均剩錢、買不起次數、reroll 次數分佈、利息收入佔比。
- 技巧差距：Lookahead 勝率 − Greedy 勝率；Greedy 位置最佳化分數 ÷ 隨機位置分數。
- 分數分佈：每 ante 單倒分數 P10/P50/P90；P90/P10 > 50 代表變異太大（運氣主導）。

## 4. 警報門檻（起點，依實測調）
| 訊號 | 門檻 | 行動 |
|---|---|---|
| 物件勝率差 | > +10pp | 削弱或提高稀有度/價格 |
| 物件勝率差 | < −5pp 且拿取率 > 20% | 陷阱卡：bot 估值錯或物件太弱 |
| 拿取率 | < 3% | 死卡：加強或重做 |
| 單一原型佔勝場 | > 40% | 削該原型 payoff 或補其他原型 enabler |
| 任一原型勝率 | < 基準一半 | 補 enabler 或 bridge |
| 強 bot 白注勝率 | > 98% | 整體太簡單 |
| Greedy 白注勝率 | < 15% | 整體太難 |
| 技巧差距（位置） | < 1.3× | 倒料位置沒意義，改反應的空間依賴 |
| 兩物件組合分數 | > 10× 兩者單獨之和 | 檢查是否刻意的難湊 combo；若好湊，限制 |

## 5. 強勢策略偵測流程
1. 對所有物件兩兩組合（或抽樣前 30 強物件）跑固定情境的「組合分數表」，找異常高的 pair。
2. 跑 archetype bot × 每個原型，看哪個原型勝率顯著高。
3. 用「固定一物件必拿」的實驗：強迫 bot 第一店買 X，看勝率提升；> +15pp 即過強。
4. 怪行為 = 訊號：bot 若一直做奇怪的事（例如只 reroll、只倒一個角落），先查 bug 與規則漏洞再調數值。

## 6. 報告格式（`docs/design/balance/YYYY-MM-DD_<主題>.md`）
```
# 平衡報告：<主題>
- 資料版本：data commit <hash>；sim 版本 <hash>；N = <局數>/bot；seed 範圍
- 改動：<這次改了什麼數值>
- 結果摘要（3 行內）
- 表：bot 勝率 / 死亡 ante 分佈 / 前 10 強 & 後 10 弱物件 / 原型佔比
- 警報：<觸發哪些門檻>
- 建議下一步：<具體數值調整>
```

## 7. 模擬的極限
- 模擬回答「數字合不合理」，不回答「好不好玩」「看不看得懂」。可讀性與爽感只能人類試玩。
- 超級試玩者與 bot 都比一般玩家強：人類勝率通常低於 Greedy bot，目標曲線要留餘裕。
- Slay the Spire 提醒：數據可能誤導——資料不反映真實遊玩時（例如 bot 不會因為看不懂而不買某物件）。
